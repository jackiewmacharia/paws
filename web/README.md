# paws-web

The paws web app, built with React and Vite. For now it's a single "coming soon" page and isn't
wired to the [api](../api) yet.

### Setup

```
pnpm install
pnpm dev
```

### Scripts

| Script | What it does |
| --- | --- |
| `pnpm dev` | Start the Vite dev server |
| `pnpm build` | Typecheck and build to `dist/` |
| `pnpm preview` | Serve the built `dist/` |
| `pnpm lint` | Run oxlint |
